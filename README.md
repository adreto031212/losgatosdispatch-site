# losgatosdispatch.com

Static landing site for the Los Gatos Dispatch newsletter (GitHub Pages). Generated by `site/dispatch/build.py losgatos` in the ai-ops repo. Edit there, rebuild, push here. The signup form posts to the n8n webhook `losgatos-dispatch-signup`, which creates the beehiiv subscription with custom fields; beehiiv → n8n → Follow Up Boss.
